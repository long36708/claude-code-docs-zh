# Slack 中的 Claude Code

> 在 Team、Enterprise、Pro、Max 和 Ultra 计划中，用什么替代早期版本的 Slack 中的 Claude Code。

早期版本的 Slack 中的 Claude Code 已停用。在未连接到 Claude Tag 的工作区中，`@Claude` 会回复该工作区尚未设置 Claude Tag。

* **Team 和 Enterprise 计划：** 如果您的频道中已有 [Claude Tag](https://claude.com/docs/claude-tag/overview)，请使用它。如果没有，请参阅[如何设置](https://claude.com/docs/claude-tag/admins/setup-overview)。要从早期版本迁移工作区，请参阅[迁移指南](https://claude.com/docs/claude-tag/admins/migrate-from-earlier)。
* **Pro、Max 和 Ultra 计划：** Claude Tag 在个人计划上不可用。如果您的账户提供 [Projects](https://code.claude.com/docs/zh-CN/claude-projects.md)，请在其中启动任务，或者在[云端会话](https://code.claude.com/docs/zh-CN/claude-code-on-the-web.md)中启动任务。
